# Credits

## The Designer Skills Pack

UX Scout can optionally leverage sub-skills from [The Designer Skills Pack](https://github.com/Owl-Listener/designer-skills) by [MC Dean](https://marieclairedean.substack.com) for enhanced persona, JTBD, and research synthesis output. These sub-skills are not required -- UX Scout works fully standalone without them.

- `design-research:discover` -- persona creation, empathy mapping, and journey mapping
- `design-research:jobs-to-be-done` -- Jobs-to-Be-Done analysis
- `design-research:synthesize` -- research data synthesis into themes and insights

## Nielsen's 10 Usability Heuristics

The heuristic evaluation framework referenced in this skill is based on [Jakob Nielsen's 10 Usability Heuristics for User Interface Design](https://www.nngroup.com/articles/ten-usability-heuristics/), originally published in 1994. These heuristics are industry-standard public domain knowledge. The bundled reference file (`plugins/ux-scout/skills/ux-scout/references/nielsens-heuristics.md`) provides definitions and scoring criteria for use during research.

## ux-heuristic-eval

The proactive heuristic application approach in UX Scout was informed by [ux-heuristic-eval](https://github.com/geekatron/jerry) by [geekatron](https://github.com/geekatron), a Nielsen's heuristic evaluation skill for Claude Code.
